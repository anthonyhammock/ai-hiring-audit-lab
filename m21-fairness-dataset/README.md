# Module 21: the synthetic applicant dataset

> **SYNTHETIC DATA. NO REAL PEOPLE.** Every row was generated by a computer program. The dataset imitates the *structure* of a bias-audit data file for an AI résumé screener; it describes no real employer, vendor, tool or applicant, and its numbers say nothing about any real group.

**Course map:** Module 21 (Statistics for fairness audits), **assignment** ("A statistical re-analysis memo"): this is the "synthetic dataset matching this structure" that the scenario says your instructor provides. You can also use it in the Lesson 02–04 labs once you have built your own simulated data as those labs ask.

## Files (`data/`)

| File | Rows | What it is |
|---|---|---|
| `applicants.csv` | 8,000 | One row per applicant: demographics, a pre-application qualification, the vendor's résumé-quality score, and the outcome at each of three stages |
| `vendor_summary.csv` | 51 | The vendor's published bias-audit summary: counts, selection rates and impact ratios per stage for sex, race/ethnicity and their intersections. Two small intersectional cells have no impact ratio and the note "excluded: statistically unreliable (small n)" |
| `external_benchmark.csv` | 5 | A stated external benchmark: the share of each race/ethnicity category in a fictional qualified labour market (for Part C's standard-deviation analysis) |
| `SHA256SUMS` | — | SHA-256 hashes of the three files. Check them first (`sha256sum -c SHA256SUMS`) and record them in your analysis plan (Part D) |

## Data dictionary: `applicants.csv`

| Column | Type | Values | Meaning |
|---|---|---|---|
| `applicant_id` | string | `A100000`–`A107999` | Synthetic identifier |
| `requisition_id` | string | `REQ-PA-101`, `REQ-PA-102`, `REQ-HR-201` | The job opening applied to |
| `application_date` | date | 2026-01-05 to 2026-07-03 | Date of application |
| `sex` | category | `Female`, `Male` | Self-reported sex, as in an EEO-1-style report |
| `race_ethnicity` | category | `White`, `Hispanic or Latino`, `Black or African American`, `Asian`, `Native Hawaiian or Other Pacific Islander` | Self-reported race/ethnicity (five categories, as the assignment specifies) |
| `prequal_score` | number | about 20–80, mean 50, SD 10 | A **pre-application** qualification measured before the tool saw the résumé (for example a standardised work-sample score). Use it as the legitimate qualification control in Part C |
| `resume_quality` | integer | 0–100 | The **vendor-generated** "résumé quality" score produced by the AI screener itself. The screening decision uses it. Think carefully before controlling for it (Part C) |
| `screen_pass` | 0/1 | | Passed the AI screen (stage 1) |
| `assessment_pass` | 0/1 or blank | blank if `screen_pass` = 0 | Passed the assessment (stage 2). Only applicants who passed the screen take it, so its denominator is screened applicants |
| `interview_invite` | 0/1 | | Invited to interview (stage 3). This is the **bottom line**: the overall selection outcome among all applicants |

There are no missing values except the structural blanks in `assessment_pass`.

## Data dictionary: `vendor_summary.csv`

| Column | Meaning |
|---|---|
| `stage` | `screen`, `assessment` (denominator: applicants who passed the screen) or `interview_invite` (bottom line, denominator: all applicants) |
| `dimension` | `sex`, `race_ethnicity` or `intersection` (sex × race/ethnicity) |
| `category` | Category label; intersections are written `Female x Asian` |
| `applicants`, `selected` | Counts in the denominator and the numerator |
| `selection_rate` | `selected / applicants`, four decimals |
| `impact_ratio` | Selection rate divided by the highest selection rate among the *reported* categories in the same stage and dimension, as the vendor computed it. Blank for the excluded cells |
| `note` | The vendor's exclusion note |

## Data dictionary: `external_benchmark.csv`

| Column | Meaning |
|---|---|
| `race_ethnicity` | Category |
| `qualified_availability_share` | The fictional benchmark share of that category among qualified people in the relevant labour market. Shares sum to 1.0 |
